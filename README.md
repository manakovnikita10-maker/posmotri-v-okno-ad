# Посмотри в окно

Учебный проект Яндекс Практикума. На странице можно найти видео с видами из окон по городу и времени суток.

## Запуск

В корне репозитория запустите локальный сервер.

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте [страницу проекта](http://localhost:8000/) в браузере.
